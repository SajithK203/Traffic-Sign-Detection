## Where AI Tools Were Used

- Generating boilerplate code structure for the Streamlit demo application (`demo/app.py`)
- Debugging YOLO training configuration YAML files (`configs/`)
- Suggesting improvements to the classical CV pipeline's HSV threshold parameters
- Improving clarity of docstrings and inline code comments across `src/`
- Assisting with CSS/JavaScript fixes in the Streamlit UI (sidebar toggle, colour contrast)
- Suggesting data augmentation parameter ranges to experiment with
- Reviewing and improving markdown formatting in the final report draft

---

## What Was NOT AI-Generated

The following were produced entirely by the group:

- Dataset annotation decisions and GTSDB format conversion logic (`src/data/convert_gtsdb.py`)
- Experiment design: choice of baselines, ablation strategy (with/without augmentation), model variants
- All training runs and hyperparameter choices
- Result interpretation and quantitative analysis in the Results section
- Failure case identification and qualitative discussion
- Individual contribution decisions and role assignments

---

## Review Process

All AI-suggested code was:
1. Read and understood by at least two group members before committing
2. Tested independently on the GTSDB dataset before being merged
3. Integrated only where it passed manual review and produced correct results
